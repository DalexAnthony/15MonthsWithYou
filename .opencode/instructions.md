# Project Instructions

## Core Rules
- Be concise. Short responses. No preamble or explanations.
- Complete tasks in one pass. Do not stop mid-task.
- Verify before claiming completion.
- Security: validate inputs, no hardcoded secrets.
- No emojis unless asked.

## Workflow
- Simple tasks: just do it directly
- Complex tasks (>3 steps): plan briefly first, then execute
- No TDD unless explicitly requested
- No brainstorming step
- No code review step unless asked

## Project
This is a web game project (HTML/CSS/JS). No frameworks, no build tools.
